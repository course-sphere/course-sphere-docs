## Base path
`/change-password`

---

## POST `/change-password/update`

### Mô tả
Đổi mật khẩu cho **user đang đăng nhập**.

Use-case:
- Người dùng đổi mật khẩu lần đầu
- Người dùng chủ động đổi mật khẩu định kỳ
- Tăng bảo mật sau khi nghi ngờ bị lộ tài khoản

### Auth
Bearer token required

```http
Authorization: Bearer <accessToken>
Content-Type: application/json
```

---

### Request body
```json
{
  "oldPassword": "string",
  "newPassword": "string",
  "confirmPassword": "string"
}
```

---

### Response 200 (Success)
```json
{
  "code": 1000,
  "message": "Đổi mật khẩu thành công",
  "result": "Password changed successfully",
  "timestamp": "2026-01-12T07:47:19.214Z",
  "path": "/change-password/update"
}
```

---

### Error cases
| HTTP | Code | Tình huống |
|---|---|---|
| 400 | — | Body không hợp lệ / thiếu field |
| 401 | — | Access token không hợp lệ hoặc hết hạn |
| 400 | — | Mật khẩu cũ không đúng |
| 400 | — | `newPassword` không khớp `confirmPassword` |
| 409 | — | Mật khẩu mới trùng mật khẩu cũ |
