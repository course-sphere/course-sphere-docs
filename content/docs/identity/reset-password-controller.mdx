> API này tuân theo [API Response Convention](/docs/api-response) của hệ thống.

## Tổng quan flow

Reset password gồm 3 bước:

1) **Request OTP**: user nhập email → hệ thống gửi OTP (qua email)
2) **Verify OTP**: user nhập OTP → hệ thống trả về `verifyToken`
3) **Reset Password**: user gửi `verifyToken` + `newPassword` → đổi mật khẩu thành công

---

## Base path
`/reset-password`

---

## POST `/reset-password/request-otp`

### Mô tả
Gửi OTP đến email của người dùng để bắt đầu quy trình reset password.

### Request (query params)
| Tên | Kiểu | Bắt buộc | Mô tả |
|---|---|---:|---|
| `email` | string | ✅ | Email tài khoản cần reset mật khẩu |

Ví dụ:
```
POST /reset-password/request-otp?email=user@example.com
```

### Response 200 (Success)
Theo chuẩn ApiResponse (đích đến):

```json
{
  "code": 1000,
  "message": "Gửi OTP thành công",
  "result": "OTP sent",
  "timestamp": "2026-01-12T08:30:00.000Z",
  "path": "/reset-password/request-otp"
}
```
---

## POST `/reset-password/verify-otp`

### Mô tả
Xác minh OTP. Nếu đúng, hệ thống trả về `verifyToken` để bước sau reset mật khẩu.

### Request (query params)
| Tên | Kiểu | Bắt buộc | Mô tả |
|---|---|---:|---|
| `email` | string | ✅ | Email tài khoản |
| `otp` | string | ✅ | Mã OTP user nhận được |

Ví dụ:
```
POST /reset-password/verify-otp?email=user@example.com&otp=123456
```

### Response 200 (Success)
```json
{
  "code": 1000,
  "message": "Xác minh OTP thành công",
  "result": {
    "verifyToken": "string"
  },
  "timestamp": "2026-01-12T08:31:00.000Z",
  "path": "/reset-password/verify-otp"
}
```
---

## POST `/reset-password/verify-token/reset`

### Mô tả
Reset mật khẩu bằng `verifyToken` đã nhận từ bước verify OTP.

### Request (query params)
| Tên | Kiểu | Bắt buộc | Mô tả |
|---|---|---:|---|
| `email` | string | ✅ | Email tài khoản |
| `verifyToken` | string | ✅ | Token nhận được khi verify OTP thành công |
| `newPassword` | string | ✅ | Mật khẩu mới |

Ví dụ:
```
POST /reset-password/verify-token/reset?email=user@example.com&verifyToken=xxx&newPassword=NewPass@123
```

### Response 200 (Success)
```json
{
  "code": 1000,
  "message": "Đặt lại mật khẩu thành công",
  "result": "Password reset successfully",
  "timestamp": "2026-01-12T08:32:00.000Z",
  "path": "/reset-password/verify-token/reset"
}
```
