## Base path
`/auth`

> API này tuân theo [API Response Convention](/docs/api-response) của hệ thống.
---

## Tổng quan luồng xác thực (Frontend)

1) Frontend gọi `POST /auth/login`
2) Backend trả:
   - `accessToken` trong response body
   - `refreshToken` được set vào **cookie (httpOnly)**
3) Frontend gọi các API protected với header:
   ```
   Authorization: Bearer <accessToken>
   ```
4) Khi access token hết hạn:
   - Gọi `POST /auth/refresh`
   - Backend đọc refresh token từ cookie và trả access token mới
5) Nếu refresh thất bại → logout user, điều hướng về trang đăng nhập

---

## Thời gian sống của token

| Token | Thời gian |
|---|---|
| Access token | `JWT_VALID_DURATION = 1800s` (30 phút) |
| Refresh token | `JWT_REFRESHABLE_DURATION = 864000s` (10 ngày) |

👉 **Frontend không cần tự quản lý refresh token**, backend xử lý hoàn toàn thông qua cookie.

---

## Endpoints

| Method | Path | Auth | Mô tả |
|---|---|---:|---|
| POST | `/login` | Public | Đăng nhập |
| POST | `/refresh` | Cookie | Lấy access token mới |
| POST | `/logout` | Bearer | Logout phiên hiện tại |
| POST | `/logout-all` | Bearer | Logout toàn bộ phiên |

## POST `/login`

### Mô tả
Đăng nhập bằng số điện thoại và mật khẩu.

### Request body
```json
{
  "phoneNumber": "0123456789",
  "password": "string"
}
```

### Response 200
```json
{
  "code": 1000,
  "message": "Đăng nhập thành công",
  "result": {
    "authenticated": true,
    "token": "<ACCESS_TOKEN>"
  },
  "timestamp": "2026-01-12T07:31:29.317390654Z",
  "path": "/auth/login"
}
```

### Hành vi đặc biệt
- Refresh token được backend set vào **cookie (httpOnly)**
- Cookie này sẽ được dùng cho API `/auth/refresh`

### Error cases
| HTTP | Code | Message |
|---|---|---|
| 400 | 4003 | Sai thông tin đăng nhập |
| 423 | — | Tài khoản bị khoá |

## POST `/refresh`

### Mô tả
Lấy access token mới từ refresh token (cookie).

### Auth
- Không cần Bearer token
- Yêu cầu browser gửi cookie hợp lệ

### Response 200
```json
{
  "code": 1000,
  "message": "Refresh token thành công",
  "result": {
    "token": "<NEW_ACCESS_TOKEN>"
  },
  "timestamp": "2026-01-12T07:35:10.123456Z",
  "path": "/auth/refresh"
}
```

### Error cases
| HTTP | Code | Message |
|---|---|---|
| 401 | — | Refresh token hết hạn hoặc không hợp lệ |

## POST `/logout`

### Mô tả
Đăng xuất phiên hiện tại (thu hồi refresh token đang sử dụng).

### Auth
Bearer token required

```http
Authorization: Bearer <accessToken>
```

### Response 200
```json
{
  "code": 1000,
  "message": "Đăng xuất thành công",
  "timestamp": "2026-01-12T07:38:19.233070205Z",
  "path": "/auth/logout"
}
```

### Error cases
| HTTP | Code | Message |
|---|---|---|
| 401 | — | Access token không hợp lệ hoặc hết hạn |

## POST `/auth/admin/users/{userId}/force-logout`

### Mô tả
Buộc đăng xuất **toàn bộ phiên đăng nhập** của một user bất kỳ.  
API này dùng cho **quản trị viên** trong các trường hợp:

- User bị lộ tài khoản
- User vi phạm chính sách
- Admin cần thu hồi toàn bộ session ngay lập tức

---

### Auth
Bearer token required (Admin)

```http
Authorization: Bearer <accessToken>
```

---

### Path parameters

| Tên | Kiểu | Bắt buộc | Mô tả |
|---|---|---:|---|
| `userId` | UUID | ✅ | ID của user cần force logout |

---

### Response 200
```json
{
  "code": 1000,
  "message": "Force logout thành công",
  "timestamp": "2026-01-12T07:47:19.214Z",
  "path": "/auth/admin/users/{userId}/force-logout"
}
```

---

### Error cases
| HTTP | Code | Message |
|---|---|---|
| 401 | — | Access token không hợp lệ hoặc hết hạn |
| 403 | — | Không có quyền thực hiện |
| 404 | — | User không tồn tại |
