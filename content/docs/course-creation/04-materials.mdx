# Phase 4: Materials

Đây là giai đoạn tạo nội dung thực tế cho bài học. Dữ liệu gửi lên là **Đa hình (Polymorphic)**, phụ thuộc vào trường `item_type`. Frontend luôn gửi kèm `lesson_id`.

- **Method:** `POST`
- **Endpoint:** `/api/v1/lessons/{lesson_id}/materials`

---

## 1. Video Material

```json
{
  "lesson_id": "lesson-1771579541228-nqabf0si8",
  "item_type": "video",
  "sort_order": 1,
  "title": "Video 1",
  "is_required": true,
  "is_preview": true,
  "video_data": {
    "video_url": "https://www.youtube.com/watch?v=Hgj5a1_zNds",
    "duration": 15,
    "description": "<p class=\"text-node\">No desc</p>"
  }
}
```

### Expected Response
BE trả về ID của Material vừa được tạo hoặc update thành công.
```json
{

  "data": {
    "id": "material-123456"
  }
}
```
